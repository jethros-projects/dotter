# README screenshot

`dotter-terminal.png` presents the actual output of `dotter --help` from Dotter
0.6.3-next.1 in a decorative terminal frame. The frame is documentation artwork, not an
additional product interface. It contains no account data or service responses.

The command runs offline. Refresh the image when the top-level help changes;
preserve its complete output and do not substitute fictional successful API
responses. The PNG is included in the npm package so the README image remains
available beside the installed documentation.

This asset is original Dotter documentation, covered by the repository's MIT
license. OpenCode inspired the README's structure; no OpenCode artwork was used.
